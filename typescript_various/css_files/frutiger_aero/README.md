# Frutiger Aero CSS kit

`frut_ae_styles.css` is framework-free and opt-in. Import it, then wrap the relevant UI with `class="frutiger-aero"`.

Useful classes include `fa-background`, `fa-glass`, `fa-glass-strong`, `fa-button fa-button--blue`, `fa-input`, `fa-chip`, and `fa-status fa-status--success`. Theme the kit by overriding `--fa-*` variables on the wrapper.
