# Synthwave CSS kit

`synth_wave_styles.css` is framework-free and opt-in. Import it, then wrap the relevant UI with `class="synthwave"`.

Use `sw-background`, `sw-panel`, `sw-grid`, `sw-button`, `sw-input`, `sw-text-glow`, and `sw-scanlines`. Override `--sw-*` variables on the wrapper to adapt its palette.
